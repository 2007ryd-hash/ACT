# 复现与数据说明

本仓库公开精选结果和轻量数值证据。无需连接机械臂即可重画两张历史图；完整训练和自主实机复现仍需要本地未发布的示范、模型、处理器及匹配硬件。

## 目录与边界

- `configs/act-100k-model.json`：成功模型保存的原始 ACT 配置；运行时 TE 覆盖另见 `configs/experiment.json`。
- `data/historical-validation.csv`：同一冻结验证集的 8 个 checkpoint 汇总及保持 state 参照。
- `data/historical-gripper.csv`：两次 10 月 10 日旧单相机试验的发送动作行，仅保留时间与夹爪两列信号。
- `data/success-01-first20s.csv` 与 `success-05-first20s.csv`：两条今天成功案例按日志时钟筛选的 0–20 秒片段，共 1,084 行。
- `evidence/`：成功过程、指标、来源相对路径与 SHA；这些路径指向原学习工作区，不表示原始文件已公开。

## 重画历史图

在 Ubuntu 主机或其他具备 Python 的电脑，使用已安装 matplotlib 的普通 Python 环境，终端工作目录为本仓库根目录。下面的命令只读 `data/`，覆盖生成两张 `assets/` 历史 PNG；不训练模型、不进入容器、不访问设备。成功会打印 `Rendered 2 historical PNG figures.`，并生成可打开的两张图。若失败，请保留命令和完整报错（Python 的最后异常行也保留），删除私人路径或秘密后再用于排错。切换目录本身不会激活 Python 环境。

```bash
python tools/render_figures.py
```

已验证绘图环境为 Python 3.12.3、matplotlib 3.11.2，字体 Noto Sans CJK SC。不同环境可使用兼容版本；中文字体缺失时应补充字体或更改图中文字，不能把方框字当验收通过。

## 从原学习工作区重建精选数据

这是资产持有者的可选离线操作。Ubuntu 主机、普通 Python 3 环境，在本仓库根目录执行；将 `/path/to/so101-learning` 换成真实学习工作区根目录。脚本只读取列出的源记录、核验原 SHA，并覆盖本仓库的精选 CSV / JSON，不接触机器人。它需要旧 Workshop 在当前中文目录名下的本地记录，以及 ACT 主实验目录；仓库本身不附带这些原始资产。

```bash
python tools/export_evidence.py --workspace /path/to/so101-learning
```

成功会打印成功案例数、精选行数、历史行数和来源数；当前版本预期 **2 / 1084 / 3574 / 29**。源文件缺失会停止；关键模型、入口及动作/视频与冻结 SHA 不一致时停止，其余来源重新登记 SHA。若失败，发回执行命令及相关错误块，不要为了通过检查删掉 SHA 验证。脚本不会自动下载数据、上传文件或启动训练。

## 本次实际训练与部署环境

Python 3.11.13、PyTorch 2.7.0+cu128、LeRobot 0.4.3，revision `e670ac5daf9b76cf5c18f632b89a8ff85c727ca6`；RTX 5060 Laptop 约 8 GiB。镜像身份、模型输入、训练参数与部署覆盖保存在 [实验配置](../configs/experiment.json)。绘图环境与训练容器是不同环境。

记录中的动作限制设置只描述当时实验，不是一条可直接运行的安全运动命令。真机复现须独立确认设备身份、相机映射、校准、初始姿态、供电、关节边界、控制时间和现场可断电条件。本仓库没有自动运动入口。

## 证据口径

历史图中的归一化 L1、今天首动作 MAE、完整块 MAE、队列影子误差各有不同分母与语义；不合并成一个跨任务排行榜。成功案例是人工现场标签加录像抽查支持，不是全部尝试的统计样本。所有数值导出保留数据来源，完整原件留在本地。

这个包可以复现已发布图表和精选数据提取；**不能仅凭这个包重训原模型或复现硬件抓放**。未公开资产的身份与配置已登记，便于之后在用户选择发布数据/模型时继续补齐。
