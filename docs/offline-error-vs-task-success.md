# 离线误差很接近，为什么实际抓取会不同？

关键在于：**平均动作误差衡量“总体有多像示范”，任务结果取决于关键时刻是否做对。两者有关，却不等价。**

## 重复动作稀释关键事件

机械臂在接近、搬运、返回和持位期间，会出现很多连续、相似的动作。真正决定抓取成败的，对准、闭爪、初次抬起、袋口释放等阶段，往往集中在较短的时间窗口。

假设关键阶段占比为 `p`，全程平均误差可分解为：

`平均误差 = (1-p) × 普通阶段平均误差 + p × 关键阶段平均误差`

当 `p` 较小时，即使关键阶段变化很大，总分也可能变化不大。反过来，模型在大量容易的相似帧上预测得更准，也可能降低总分，却没有修好夹取瞬间。这是平均指标的数学性质，不需要把关键帧假设成某个固定百分比。

这里的“重复”包括缓慢或连续运动，**不等于静止**。本项目尚未对今天的全部示范逐帧标注抓取关键阶段，因此没有实测关键帧占比，也不能声称这一因素已被证明是效果差异的唯一原因。

## 本项目的具体证据

2026-10-26 的同一独立验证集包含 5 条示范、2,337 帧。两版双摄像头模型使用同一评估代码、相同标签与 padding、数值等价的有效归一化统计。模型输入仅为双图和实测 state，不读取专家 action。

50 条 / 100K 与后来 70 条加权微调 30K 的**每帧新预测首动作 MAE**分别为 **2.6029 与 2.4579**，下降 **5.57%**。非 padding 的 100 步块 MAE 为 **7.4889 与 7.1369**；每 100 帧取块的离线队列影子为 **8.4090 与 7.4701**。各项分母与预测方式不同，应各自纵向比较。

最直观的参照是：将实测 state 直接复制成当前动作目标，首步 MAE 只有 **1.9872**，低于上述模型。这个参照在专家轨迹上每帧获得真实的新状态，相当于持续得到专家已完成运动的信息；若实际部署只命令保持当前位置，它不会主动完成抓取。因此不能用较低的离线分数推断更高的抓取能力。

这些数值的单位为 SO-101 标定关节单位，不是角度、厘米或末端误差。旧外部单相机图采用归一化 L1、另一组数据和聚合方式，不能把它的约 0.06 与今天的约 2.5 当成同一量纲比较。[指标摘要](../evidence/offline-comparison.json)

## 抓取有门槛，闭环会累积偏差

夹爪只差一点位置、姿态或闭合时间，就可能从夹住变为抓空。后续即使搬运轨迹很像示范，空手到袋口也不能完成任务。关节空间 MAE 又把六个维度平均，不能直接表达末端接触几何。

离线评估的下一帧仍来自专家示范；真实机器人下一帧由模型刚才的动作决定。一次抓偏会改变物体位置、画面和关节状态，后面的输入随之偏离示范。这个闭环分布变化与误差累积问题是模仿学习的已知困难，参见 [Ross 等人的 DAgger 论文](https://proceedings.mlr.press/v15/ross11a.html)。[ACT 原论文](https://arxiv.org/abs/2304.13705) 也围绕精细操作与动作序列预测处理这类问题；这并不证明本实验的具体因果。

本次离线首动作指标对应每帧重新预测、TE 关闭的取法；今天成功案例开启 TE。100 步队列影子也不等于 TE 的实际执行方式。模型设置、起始姿态、物体布局和控制时间都可能影响实机表现。

## 我们怎样解释今天的成功

今天已核的两条成功案例来自 **50 条 / 100K**，没有将其移记为后来 30K 微调的收益。双视角提供互补观测、成对采集的数据、训练好的策略和 TE 单步执行共同构成成功的配置。

“关键阶段占比小，所以平均误差可能掩盖任务差异”是合理且重要的指标解释。要进一步证明是哪一项改动带来改善，下一轮需要在相同起点、布局与推理设置下比较，并分别检查接近、夹取、抬起、释放阶段；本仓库没有把尚未完成的实验写成既定结论。
